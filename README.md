## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Pre-Game Analysis** | Full champion stats, runes and builds before you enter champion select |
| **Live Tracking** | Real-time team and enemy performance during the match |
| **Post-Match Review** | Detailed breakdown of every play and decision after the game |
| **Multi-Game** | Supports League, VALORANT, TFT and other major titles |
